# TfL Claude

A Transport for London mobile app built with Expo SDK 54 and Expo Router.

## Setup

1. Copy `.env.example` to `.env` and add your TfL API key:
   ```
   cp .env.example .env
   ```

2. Install dependencies:
   ```
   npm install
   ```

3. Start the development server:
   ```
   npx expo start
   ```

Scan the QR code with Expo Go (v54.0.6) on your device.
